# NovelFlow

**NovelFlow**는 [TetraTheta/np-viewer](https://github.com/TetraTheta/np-viewer)를 기반으로 TTS 기능을 추가한 파생 프로젝트입니다.

원본 NP Viewer의 가벼운 WebView 기반 구조와 노벨피아 뷰어 기능을 유지하면서, 노벨피아 공식앱과 다르게, 구글 TTS 강제 사용이 아닌 시스템 TTS 엔진 사용 기능, TTS 전용 정규식 처리, 문장 강조 표시, 정주행, 다음 회차 미리 로딩 및 백그라운드 재생** 등의 기능을 추가했습니다.

> [!NOTE]
> NovelFlow는 노벨피아의 공식 애플리케이션이 아니며, 노벨피아 및 운영 주체와 제휴·협력·공식적인 관계가 없는 비공식 애플리케이션입니다.

## 주요 기능

### 📖 기본 뷰어

원본 NP Viewer의 주요 기능을 유지합니다.

* 노벨피아 WebView 기반 뷰어
* 페이지 로딩 진행률 표시
* 당겨서 새로고침
* 시작 페이지 설정

  * 홈페이지
  * 최근 본 작품
  * 내 서재
* 노벨피아 링크 처리
* 노벨피아 외부 링크의 시스템 브라우저 처리
* 뒤로 가기 / 앞으로 가기
* 볼륨 키를 이용한 페이지 이동
* 볼륨 키 페이지 이동 방향 설정
* 당겨서 새로고침 동작 영역 설정

### ⭐ 즐겨찾기

작품의 URL을 앱 내부에 즐겨찾기로 저장할 수 있습니다.

* 즐겨찾기 추가
* 즐겨찾기 수정
* 즐겨찾기 삭제
* 즐겨찾기 순서 변경
* 즐겨찾기 목록 내보내기
* 즐겨찾기 목록 불러오기
* 잘못된 URL 및 중복 URL 검사

즐겨찾기는 앱 내부에 저장되며, 설정 백업에도 포함할 수 있습니다.

## 🛡️ 광고 차단

원본 NP Viewer의 광고 차단 필터 기능을 유지하면서 네트워크 필터와 CSS 기반 요소 숨김 기능을 제공합니다.

### 필터 구독

외부 필터 목록을 URL로 등록하여 사용할 수 있습니다.

* 필터 목록 구독
* 앱 실행 시 필터 자동 업데이트
* 수동 필터 업데이트
* 구독 필터 목록 초기화

### 사용자 필터

사용자가 직접 네트워크 차단 및 요소 숨김 규칙을 추가할 수 있습니다.

* 사용자 지정 네트워크 필터
* CSS 기반 요소 숨김 규칙
* 도메인별 요소 숨김 규칙
* 허용 / 차단 규칙

필터 파서는 지원하지 않는 규칙을 무시하며, 잘못된 필터 하나 때문에 앱 전체가 종료되지 않도록 처리되어 있습니다.

자세한 필터 문법은 원본 프로젝트의 문서를 참고하시기 바랍니다.

[NP Viewer 광고 차단 필터 안내](https://github.com/TetraTheta/np-viewer#광고-차단-필터-안내)

# 🔊 TTS

NovelFlow의 가장 큰 추가 기능입니다.

노벨피아에서 현재 보고 있는 회차의 본문을 Android의 TTS 엔진을 이용해 읽어줍니다.

Android 표준 `TextToSpeech` API를 사용하므로, 실제 음성 및 음질은 기기에 설치된 TTS 엔진과 음성 데이터에 따라 달라집니다.

기본적으로 **한국어 TTS**를 사용합니다.

## TTS 재생 기능

TTS 플레이어에서는 다음 기능을 제공합니다.

* 재생 / 일시정지
* 이전 문장
* 다음 문장
* 문장 단위 탐색
* 진행 위치 표시
* 진행 막대를 통한 위치 이동
* 현재 읽고 있는 문장 표시
* 현재 읽고 있는 문장 **본문 강조 표시**
* 현재 문장으로 자동 스크롤
* TTS 재생 속도 변경
* `한 화` / `정주행` 모드
* 회차 종료 후 다음 회차 자동 재생

### 재생 속도

현재 다음 재생 속도를 지원합니다.

```text
0.8x
1.0x
1.2x
1.5x
2.0x
```

---

## 🟨 현재 읽는 문장 강조 표시

TTS가 문장을 읽기 시작하면 해당 문장이 WebView의 본문에서 자동으로 강조 표시됩니다.

단순히 플레이어에 현재 문장 번호를 표시하는 것이 아니라, 실제 웹페이지 본문에서 **현재 TTS가 읽고 있는 문장을 시각적으로 강조**합니다.

문장이 변경되면 강조 위치도 자동으로 변경되며, 현재 문장이 화면 밖에 있는 경우 해당 위치로 자동 스크롤합니다.

문장 강조에는 브라우저의 `CSS Highlights API`를 사용합니다.

또한 화면 회전이나 WebView DOM 갱신 등으로 본문이 다시 생성되는 경우에도 현재 TTS 위치를 기준으로 강조 표시와 스크롤 위치를 복구하도록 처리되어 있습니다.

# 📝 TTS 텍스트 처리

NovelFlow는 WebView에 표시되는 원문 자체를 수정하지 않습니다.

TTS에 실제로 전달하는 문자열만 별도로 가공하여 한국어 TTS에서 어색하게 읽힐 가능성이 높은 표현을 보정합니다.

현재 기본 처리에는 다음과 같은 항목이 포함됩니다.

* 불필요한 공백 제거
* 줄바꿈 및 탭 정리
* Zero-width space 및 불필요한 공백 문자 제거
* 분수 표기 변환
* 소수점 표기 변환
* 천 단위 쉼표 정리
* 퍼센트 기호 발음 보정
* 통화 기호 발음 보정
* 단위 발음 보정

예를 들어 다음과 같은 표현을 TTS에 보다 적합한 형태로 변환합니다.

```text
3.1/100
→
3.1 나누기 100
```

```text
3.1
→
3 점 1
```

```text
1,000
→
1000
```

```text
10kg
→
10 킬로그램
```

```text
5km
→
5 킬로미터
```

지원되는 기본 단위에는 다음과 같은 항목이 포함됩니다.

```text
%
$
¥
€
kg
km
cm
mm
m
g
ml
l
```

이러한 변환은 **TTS에 전달되는 텍스트에만 적용**되며, WebView에 표시되는 원문은 그대로 유지됩니다.

# 🔧 TTS 정규식

NovelFlow에는 별도의 **TTS 정규식 설정** 기능이 있습니다.

웹소설의 특정 표현을 사용자가 원하는 발음이나 형태로 바꾸고 싶을 때 사용할 수 있습니다.

각 규칙은 다음과 같은 설정을 가집니다.

* 규칙 활성화 / 비활성화
* 검색 패턴
* 치환 문자열
* 일반 문자열 치환 / 정규식 모드
* 대소문자 무시
* 규칙 순서

규칙은 설정된 순서대로 적용됩니다.

## 일반 문자열 치환

일반 문자열 모드에서는 지정한 문자열을 그대로 찾아 치환합니다.

## 정규식 치환

정규식 모드에서는 Java 정규식 문법을 사용할 수 있습니다.

캡처 그룹을 사용할 수 있으며 `$1`, `$2` 등의 치환 문자열도 지원합니다.

예:

```text
검색:
(\d+)kg

치환:
$1 킬로그램
```

입력:

```text
12kg
```

TTS 처리 결과:

```text
12 킬로그램
```

# 📚 정주행

TTS는 두 가지 재생 모드를 제공합니다.

### 한 화

현재 보고 있는 회차만 재생합니다.

현재 회차가 끝나면 재생을 종료합니다.

### 정주행

현재 회차가 끝나면 다음 회차로 이동하여 TTS를 계속 재생합니다.

다음 회차가 아직 준비되지 않은 경우에도 다음 회차의 본문을 가져오기 위한 재시도 및 전환 처리가 포함되어 있습니다.

---

# ⚡ 다음 회차 미리 로딩

정주행 모드에서는 현재 회차를 읽는 동안 **다음 회차를 미리 준비**할 수 있습니다.

다음 회차의 본문을 별도의 WebView에서 미리 로딩하고 내용을 수집해 두어, 현재 회차가 끝났을 때 다음 회차 TTS를 보다 빠르게 시작할 수 있도록 합니다.

다음 회차의 본문을 바로 가져오지 못하는 상황에 대비해 재시도 및 페이지 새로고침 처리도 포함되어 있습니다.

---

# 🌙 화면을 꺼도 계속 듣기

TTS는 화면이 꺼진 상태에서도 계속 재생될 수 있도록 설계되어 있습니다.

이를 위해 다음 Android 기능을 사용합니다.

* Foreground Service
* `WakeLock`
* `WifiLock`
* Android MediaSession
* 미디어 재생 알림

따라서 화면을 끄거나 다른 앱을 사용하는 상황에서도 TTS가 계속 재생될 수 있습니다.

단, 실제 백그라운드 동작은 제조사의 배터리 최적화 정책이나 시스템 설정에 따라 달라질 수 있습니다.

# 🔗 노벨피아 링크 처리

# 🛠️ 빌드

NovelFlow는 Android Studio 또는 Gradle Wrapper를 이용해 빌드할 수 있습니다.

## 개발 환경

```text
Android compile SDK : 37
Android target SDK  : 36
최소 지원 SDK       : 31
Java                : 17
Kotlin JVM Toolchain : 17
```

### 디버그 빌드

Windows:

```powershell
.\gradlew.bat assembleDebug
```

### Prerelease 빌드

```powershell
.\gradlew.bat assemblePrerelease
```

Prerelease 빌드는 Release 설정을 기반으로 하지만 디버그 서명을 사용합니다.

### Release 빌드

Release 빌드에는 서명 정보가 필요합니다.

```text
KEYSTORE_PATH=
KEY_ALIAS=
KEYSTORE_PASSWORD=
KEY_PASSWORD=
```

`KEY_PASSWORD`가 지정되지 않은 경우 `KEYSTORE_PASSWORD`가 사용됩니다.

서명된 APK 빌드:

```powershell
.\gradlew.bat :app:buildReleaseApk
```

빌드가 완료되면 APK는 저장소의 `apk` 디렉터리에 복사됩니다.

# 📌 원본 프로젝트

NovelFlow는 다음 프로젝트를 기반으로 ChatGPT의 도움을 받아 개발되었습니다.

**NP Viewer**

https://github.com/TetraTheta/np-viewer

원작자:

**TetraTheta**
NovelFlow는 원작자이신 TetraTheta님의 허락을 받아 NP Viewer를 포크하여 기능을 추가한 프로젝트입니다.
원본 프로젝트의 저작권 및 라이선스 정보를 유지하면서 별도의 프로젝트 이름, 패키지명 및 브랜딩을 사용하여 원본 **NP Viewer**와 명확하게 구분되도록 했습니다.

---

# 🙏 원본 프로젝트에 대한 크레딧

NovelFlow는 NP Viewer의 코드와 구조를 기반으로 하고 있습니다.

원작자의 요청에 따라 다음 사항을 준수합니다.

* **NP Viewer와 명백히 구분되는 이름 사용**
* **원본 프로젝트 및 원작자에 대한 크레딧 유지**
* **GPLv3 라이선스 준수**

NovelFlow에서 추가되거나 변경된 주요 기능은 다음과 같습니다.

* TTS 재생
* 현재 읽는 문장 강조 표시
* 문장 단위 TTS 탐색
* TTS 텍스트 전처리
* 사용자 지정 TTS 정규식
* TTS 정규식 테스트 및 미리듣기
* 한 화 / 정주행 모드
* 다음 회차 미리 로딩
* 백그라운드 TTS 재생
* 미디어 알림 및 MediaSession 연동
* 화면 꺼짐 상태의 TTS 재생 대응
* 기타 NovelFlow 전용 UI 및 기능
