# NovelFlow v0.1

- Independent package ID: `com.novelflow.app` so NovelFlow and the original NP Viewer can be installed side-by-side.
- Version name: `0.1`.
- TTS path restored from the previously working NP Viewer TTS build; `window.__npTts` and the internal TTS bridge protocol are intentionally preserved.
- The visible app name and branding are NovelFlow.
- Launcher/installer icon uses the provided NovelFlow book icon image across legacy and adaptive icon resources.
- The screen-off chapter-transition experiment is intentionally not included in this v0.1 baseline; first verify TTS stability, then reintroduce that change separately.
